PORTOFOLIO ABDUL MALIK (web statis: HTML, CSS, JavaScript)

CARA MENJALANKAN
1. Ekstrak ZIP, buka folder abdul-malik-portfolio.
2. Klik dua kali index.html (terbuka di browser, tanpa server). Internet hanya dipakai untuk font Google; tanpa internet tampilan memakai font cadangan.

YANG PERLU ANDA ISI
- Kontak: js/script.js, objek CONTACT di baris paling atas. Tombol otomatis aktif setelah diisi.
- Foto proyek: simpan sebagai assets/images/robot-malik.jpg, smart-river-cleaner.jpg, website-iot.jpg
- CV asli: ganti assets/cv/abdul-malik-cv.pdf (CV bawaan hanya sementara)

PENJELASAN UNTUK DOSEN
- index.html: struktur halaman (HTML5 semantik). css/style.css: tampilan (variabel warna, grid, flexbox, glassmorphism, media query responsif).
- js/script.js: navbar sticky, menu hamburger, scroll reveal (IntersectionObserver), lightbox, tombol kontak, tahun copyright otomatis.
- Statis: tanpa backend, database, atau login.
